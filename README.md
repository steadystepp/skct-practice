# 심층역량 연습소

SKCT 심층역량검사 형식으로 연습하고, 응답 품질 지표까지 확인할 수 있는 웹 도구입니다.
파일 하나로 동작하며 서버가 없습니다. 모든 응답은 브라우저 안에서만 처리되고 어디에도 전송되지 않습니다.

## 무엇을 하나

- **PART 1** — 3문항 세트에 6점 척도로 답하고, 세트마다 가장 가까운 문항과 가장 먼 문항을 고릅니다 (80세트 240문항)
- **PART 2** — 단일문항 6점 척도 (150문항)
- 실전(390문항 70분) 외에 절반·체험 분량으로도 응시할 수 있습니다

## 리포트 8개 섹션

| 섹션 | 내용 |
|---|---|
| 01 종합 요약 | 1단계 신뢰도 판정(바람직성 / 비일관성), 업무 유형, 종합 점수 |
| 02 SK 일하는 방식 | 자발성·높은 목표·틀을 깨는 시도 등 7개 항목 |
| 03 업무가치 | 과정↔성과, 안정↔변화 등 6개 축에서의 위치 |
| 04 업무행동 특성 | 9개 척도 레이더 차트와 해석 |
| 05 지원직무 Fit | 4개사 15개 직무 목표 프로필과 비교 |
| 06 결과판단 | 검사 유효성, 응답 편향, 미응답 |
| 07 응답 점검 | 목표 대비 차이, 정방향·역방향 비교, 내 응답 전체 |
| 08 흔들린 지점 | 가운데에 걸리거나 앞뒤가 어긋난 척도와 그 문항 |

## 특징

- **1단계 신뢰도 판정** — 바람직성과 비일관성 중 하나만 기준을 넘어도 걸리는 구조로 표시합니다
- **내 문항으로 응시** — 가지고 있는 문항 텍스트를 붙여넣으면 그 문항으로 검사가 돌아갑니다. 척도 분류는 자동으로 붙고, 직접 수정하거나 분류표 파일로 얹을 수도 있습니다
- **PDF 저장** — 리포트 전체를 인쇄용으로 펼쳐 저장할 수 있습니다

## 쓰는 법

`index.html`을 브라우저로 열면 끝입니다. 설치나 빌드가 필요 없습니다.

GitHub Pages로 올리려면 저장소 Settings → Pages → Source를 `main` 브랜치 `/ (root)`로 지정하면 됩니다.

## 알아두실 것

- 이 사이트는 **SK그룹 및 SKCT 운영사와 무관한 개인 연습용 도구**입니다
- 문항, 척도 구성, 직무 목표 프로필, 판정 기준선은 모두 자체 제작한 것으로 실제 검사의 채점 방식과 다릅니다
- 종합 점수와 구간 표시는 규준집단에 근거한 백분위가 아니라 응답을 100점으로 환산한 값입니다
- 결과는 합격 가능성을 예측하지 않습니다. 회차 간 비교와 형식 적응 용도로 사용하세요
- 중간 저장이 없습니다. 새로고침하면 응답이 사라집니다
